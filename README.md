# Portal de Pacientes - Laboratorio Clínico

Página de una sola vista para ejecutar casos de prueba con Selenium IDE.

## URL

https://leoprogramer.github.io/portal-pacientes-lab/

## Casos de prueba

- PF-06: Inicio de sesión con credenciales incorrectas
- PF-07: Recuperación de contraseña (flujo en 3 pasos: identificación, código, nueva contraseña)
- PF-08: Consulta de resultados médicos
- PF-09: Visualización del detalle de un resultado
- PF-10: Descarga de resultados médicos

## Datos de prueba

- usuario: `paciente@test.com`
- contraseña: `paciente123`
- documento válido: `1234567890`
- código de verificación: `123456`
